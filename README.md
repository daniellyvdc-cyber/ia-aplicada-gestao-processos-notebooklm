# IA Aplicada à Gestão de Processos com NotebookLM

## 📌 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de utilizar o NotebookLM como ferramenta de aprendizagem ativa.

O tema escolhido foi **Inteligência Artificial aplicada à Gestão de Processos**, explorando como a IA pode apoiar atividades de análise, documentação, melhoria e transformação de processos organizacionais.

## 🎯 Objetivos

- Compreender aplicações da Inteligência Artificial na Gestão de Processos;
- Identificar oportunidades de utilização da IA ao longo do ciclo de BPM;
- Analisar benefícios, riscos e limitações;
- Experimentar técnicas de engenharia de prompts;
- Construir um miniguia para futuras consultas e revisões.
